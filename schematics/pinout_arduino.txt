CONNEXIONS DÉTAILLÉES PAR FONCTION

┌─────────────────────────────────────────────────────────────┐
│ CAPTEUR DHT22 (Temp + Humidité)                             │
│                                                             │
│  DHT22 Pin 1 (VCC)  → Arduino 3.3V                         │
│  DHT22 Pin 2 (DATA) → Arduino Pin 2                        │
│  DHT22 Pin 2 (DATA) → Arduino 3.3V via [10kΩ] (pull-up)   │
│  DHT22 Pin 4 (GND)  → Arduino GND                          │
│                                                             │
│  Longueur câble max : 2m (au-delà, augmenter résistance)    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ CAPTEUR HC-SR04 (Distance ultrasonique)                     │
│                                                             │
│  HC-SR04 VCC  → Arduino 5V                                 │
│  HC-SR04 TRIG → Arduino Pin 3 (OUTPUT)                     │
│  HC-SR04 ECHO → Arduino Pin 4 (INPUT)                      │
│  HC-SR04 GND  → Arduino GND                                │
│                                                             │
│  Position recommandée : façade, à 25-30cm du bac           │
│  Zone de détection : 5-55cm                                 │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ MICROPHONE MAX9814 (Son ambiant)                            │
│                                                             │
│  MAX9814 VDD → Arduino 3.3V                                │
│  MAX9814 GND → Arduino GND                                 │
│  MAX9814 OUT → Arduino A0 (+ condensateur 10µF GND)        │
│  MAX9814 AR  → Non connecté (gain = 40dB par défaut)        │
│                                                             │
│  Câble BLINDÉ obligatoire (coaxial fin)                     │
│  Position : sous le bac, orienté vers les visiteurs         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ LCD 20×4 I2C                                                │
│                                                             │
│  LCD GND → Arduino GND                                      │
│  LCD VCC → Arduino 5V                                       │
│  LCD SDA → Arduino Pin 20 (SDA)                            │
│  LCD SCL → Arduino Pin 21 (SCL)                            │
│                                                             │
│  Adresse I2C : 0x27 (défaut) ou 0x3F                        │
│  Si écran non détecté → lancer "I2C Scanner" sketch        │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ENCODEUR ROTATIF KY-040                                     │
│                                                             │
│  KY-040 CLK → Arduino Pin 9 (INPUT_PULLUP)                 │
│  KY-040 DT  → Arduino Pin 10 (INPUT_PULLUP)                │
│  KY-040 SW  → Arduino Pin 11 (INPUT_PULLUP)                │
│  KY-040 VCC → Arduino 5V                                   │
│  KY-040 GND → Arduino GND                                  │
│                                                             │
│  Utilisation : ajustement vitesse ±20%                      │
│  (tourner = ±2%/clic, appuyer = réinitialiser)             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ BOUTON MODE (Pause/Reprendre)                               │
│                                                             │
│  Un côté → Arduino Pin 7 (INPUT_PULLUP)                    │
│  Autre côté → Arduino GND                                  │
│                                                             │
│  Action : bascule entre MODE_RUNNING ↔ MODE_PAUSED          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ BUZZER PASSIF                                               │
│                                                             │
│  Buzzer (+) → Arduino Pin 8                                │
│  Buzzer (-) → Arduino GND                                  │
│                                                             │
│  Note : buzzer PASSIF (piézo sans oscillateur interne)     │
│  Un buzzer actif jouera juste un bip monotone.             │
└─────────────────────────────────────────────────────────────┘
